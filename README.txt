VNO APP - PRIMER PROTOTIPO

1. Abre index.html en un navegador para ver la primera pantalla.
2. El siguiente paso será crear el formulario de presupuesto.
3. Después añadiremos fotos, WhatsApp, llamadas y una zona de administración.

Este prototipo está pensado para evolucionar a una PWA instalable sin pagar por una app nativa.
